What the buttons on this page do tap to expand
Merge
Import a JSON or Excel file and overwrite matching keys in this locale, adding any keys that are new. Touched rows are tagged merged and flagged Needs review.
Merge Missing Translations
Fill only the untranslated (empty) entries already in this locale; existing translations are left untouched. Filled rows are tagged merged new translation and flagged.
Merge New Translations
Insert only keys that don't exist in this locale yet, with their English source and translation. Existing keys are ignored. New rows are tagged inserted new translations and flagged.
Export Selected
Download the tick-selected rows as a POEditor-format Excel (.xlsx) file. Enabled once you tick at least one row.
Export CSV
Download the rows currently shown as a CSV — the active filter, search, and section narrow what's exported.
Export Locale (JSON)
Download this one locale as a POEditor-format JSON file (the shape the Excel Tool extracts).
Undo
Step back through the last 10 changes, across every locale.
Flag & tags
The flag button toggles a row's Needs review state. The × on a tag removes it; removing a row's last tag also clears its review flag.
Approve / Approve All
Shown on the Needs review filter — clear the review flag on the selected, or on all shown, flagged rows.
